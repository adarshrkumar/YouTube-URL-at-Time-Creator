# YouTube-URL-at-Time-Creator

A simple tool to generate YouTube URLs with timestamp parameters.

## Usage

1. Enter a YouTube video ID
2. Enter the timestamp in `MM:SS` format
3. Click "Convert" to generate the timestamped URL

## Example

- Video ID: `dQw4w9WgXcQ`
- Time: `1:30`
- Output: `https://youtube.com/watch?v=dQw4w9WgXcQ&t=90`
